# Homebrew tap for Campfire

```bash
brew install boringinfraco/campfire/campfire
```

This installs the checksummed GitHub Release archive for Campfire. Homebrew also installs its keg-only Node.js 22 and puts that `node` on `PATH` for the `campfire` command. The install does not start a service and does not send telemetry.

The formula pins the same archives as [BoringInfraCo/Campfire](https://github.com/BoringInfraCo/Campfire). Apache-2.0.
